# School Hub (23)

Create a responsive school management website using React and TypeScript. Create a public website with Home, About, Principal Message, Faculty, Admissions, Gallery, News, Daily Quote, Results, Events and Contact pages. Create separate Admin, Teacher and Student dashboards with role-based navigation. Use a professional school design and make everything responsive

Add an admin news management page with create, edit, delete and publish functionality.

Add an image gallery management page with multiple image upload and album management.

Add an online admission form with student details, parent details, academic information and document upload
